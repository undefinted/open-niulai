# Code Of Conduct

Be respectful, specific, and constructive. Critique work rather than people. Do not submit harassment, hateful material, sexualized depictions of real people, doxxing, impersonation, or media intended to mislead viewers about endorsement or authorship.

Project maintainers may remove contributions or participation that violate these expectations. Reports should use the same private channel described in `SECURITY.md` when public discussion would expose a person or sensitive material.
