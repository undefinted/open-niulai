# 模型连接中心

Open NiuLai 使用统一的供应商能力清单管理视频模型。连接方式分为 OAuth、临时 API Key、平台跳转和本地模型四类。

## 当前支持

| 平台 | 当前方式 | 说明 |
| --- | --- | --- |
| MiniMax H3 | 临时 API Key | HTTPS 部署后开放，凭证只保存在进程内存中 |
| Runway | 临时 API Key | HTTPS 部署后开放，凭证只保存在进程内存中 |
| 可灵 | 平台跳转 | 下载或复制制作包后在平台官网生成 |
| Seedance | 平台跳转 | 下载或复制制作包后在平台官网生成 |
| 本地 SVD | 演示 | 展示仓库内经过来源与媒体检查的样片 |

## OAuth 扩展边界

只有供应商公开第三方应用注册、授权端点、令牌端点、scope 和撤销机制后，才能启用正式 OAuth。项目不会复用其他应用的 client_id，也不会用网页登录 Cookie 模拟授权。

## 安全规则

- 公网 HTTP 请求不能提交 API Key。
- Key 不写文件、数据库、响应或日志。
- 临时连接四小时过期，服务重启后立即清除。
- 浏览器只持有 HttpOnly、SameSite=Strict 的随机会话标识。
- 正式部署需要 HTTPS，并应在反向代理中传递 X-Forwarded-Proto。
- 真实付费生成必须另设明确确认步骤，不能因连接账户自动扣费。
