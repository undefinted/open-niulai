# Open NiuLai 执行计划

## 北极星

让用户在 60 秒内把任意一句 prompt 变成一个可继续生成图片、视频并发布的原创《X来》项目。

北极星指标：每 100 个生成项目中，被用户导出图片、复制视频 prompt 或继续要求生成成片的项目数。

## 产品定位

一句话：`你输入一个东西，它真的来了。`

核心用户是想追热点但不会写剧本、不会搭 AI 视频工作流的创作者，以及希望快速制作圈层梗的开发者、运营和自媒体团队。

真正壁垒不是一种画风，而是四层闭环：

1. Prompt 共创：保留用户意图，自动补齐冲突、反转与台词。
2. 生产资产：角色参考、首帧、正片截图、分镜和后端 prompt。
3. 视频适配：按 Runway、Kling、Seedance 的使用方式输出。
4. 传播设计：每个项目自带封面、标题、首评和下一题材邀请。

## 阶段与验收

### P0：可复现的内容引擎（当前 MVP）

- Codex Skill 能从极短 prompt 生成完整内容包。
- CLI 支持 JSON 与 Markdown。
- 用户显式约束进入 `constraint_report`。
- 5/15/30 秒脚本时间轴连续、无重叠、无越界。
- 三个视频后端均有可复制提示词。
- 至少提供《猫来》《甲方来》《代码来》三个跨圈层示例。

### P1：直接图片闭环

- Skill 在可用时直接调用图片生成工具。
- 每个 demo 至少有海报、正片截图两张图。
- 建立角色参考图到首帧图的一致性检查清单。
- 发布首屏使用真实样片，而不是功能截图。

### P2：直接视频闭环

- 优先接入一个可自动化后端，候选首选 Runway。
- 用户确认外部调用和费用后，提交首帧与镜头 prompt。
- 返回原视频、带字幕版和可复用项目清单。
- Kling、Seedance 在没有直接接口时保持导出包模式。

### P3：传播与社区

- 建立“本周谁来”固定栏目。
- 允许用户提交一个词，维护公开 gallery。
- 每周固定测试 3 个圈层：大众情绪、职场、开发者。
- 记录生成到发布漏斗，不用 star 数替代真实使用。

## 首发打法

首屏只讲一件事：输入一个词，得到海报、崩坏正片和短片制作包。

首发七题材：`猫来`、`狗来`、`甲方来`、`代码来`、`老板来`、`股来`、`AI来`。动物题材负责理解门槛，职场和代码题材负责转发身份认同，股市与 AI 题材负责时效传播。

每条演示都使用同一个结构：

1. 0-1 秒：精致海报或大冲突字幕。
2. 1-4 秒：硬切到真诚崩坏的正片。
3. 4-7 秒：一句可复述台词。
4. 结尾：`下一个你想看谁来？`

## 增长实验

| 实验 | 假设 | 指标 | 保留条件 |
| --- | --- | --- | --- |
| 海报 vs 正片对照 | 反差提高停留 | 3 秒留存 | 比单图高 20% |
| 用户点题 | 参与感带来评论 | 评论率 | 超过账号基线 30% |
| 圈层题材 | 身份梗提高转发 | 分享率 | 超过动物题材 15% |
| 一键内容包 | 降低制作门槛 | 导出/复制率 | 超过 25% |
| 开源模板挑战 | UGC 带来项目发现 | 外部作品数 | 首月 20 个有效作品 |

## 风险与对策

- 热点衰减：品牌从“牛来模仿器”升级为“低成本真诚崩坏短片引擎”。
- 输出同质化：随机性放在题材、任务和反转，角色一致性与结构保持稳定。
- 视频成本：默认先生成 5 秒单镜头验证，用户确认后再扩展 15/30 秒。
- IP 风险：不内置原作角色、截图、Logo、逐句台词或镜头复刻。
- 模型不可控：把字幕放到剪辑阶段，角色动作保持简单，每镜头只做一个动作。

## 两周推进节奏

- 第 1-2 天：固化 Skill、CLI、测试与示例。
- 第 3-4 天：生成首发视觉样片，打磨 README 首屏。
- 第 5-7 天：用 10 个真实 prompt 做盲测，修复约束遗漏。
- 第 8-10 天：接入或手工跑通一个视频后端，产出 3 条短片。
- 第 11-12 天：发布 GitHub、小红书/B站/抖音演示，收集点题。
- 第 13-14 天：复盘留存、评论、复制率，决定下一批模板。

## 当前完成定义

仓库达到可公开预览的 MVP：Skill、CLI、测试、示例、计划与视觉样片齐备。真正的 direct-video 仍是下一里程碑，需要选定并授权外部视频服务。

- `P3` 完成：统一 CLI 支持 prompt 建项、资产登记、三后端作业、状态查询与真实视频归档；wheel 可构建，端到端项目测试通过。

- `P5` 进行中：七题材 campaign 与完整文本制作包、角色参考、首帧、海报和本地视频作业/预览已齐备；三项 A/B 实验、真实事件表、加权指标与最小样本判定器已建立。尚未对外发布，因此没有真实平台数据。
