# Script Workflow

Read this for concepts, scripts, dialogue, or complete packages.

## Parse Before Expanding

Preserve the user's subject, exact dialogue, plot beats, tone, duration, platform, and exclusions. Record them in a `constraint_report`. Fill only missing fields.

Default duration is 15 seconds. Use a simple story grammar: blunt title, naive original protagonist, emotionally clear mission, absurd environment, one repeatable line, and a sincere but ridiculous reveal.

Do not force the mother motif. Alternatives include a boss, home, money, a missing semicolon, an order, an exam score, or any hook implied by the user.

## Timing

- 5s: establish (0-1), one stiff action and line (1-3), reveal/title (3-5).
- 15s: hook (0-3), mission (3-7), escalation (7-12), reveal (12-15).
- 30s: hook (0-5), problem (5-10), journey (10-18), reversal (18-25), title/comment hook (25-30).

Keep every shot generatable: one subject, one main action, short dialogue, minimal hand interaction, no crowd unless requested.

## Full Package Fields

Return title, hook, constraint report, character bible, world, script, shot table, image assets/prompts, backend-specific video prompts, subtitles/voiceover, editing notes, and publishing copy.
