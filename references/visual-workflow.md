# Visual Workflow

Read this for direct images or image prompts. Use the available image generation tool when the user asks for actual images.

For an asset set or video project, read [character-consistency.md](character-consistency.md) first. Generate the character reference before scene frames and keep its identity-lock fields verbatim.

## Modes

`poster_scam`: elegant, emotional animated-film poster; painterly or ink-wash mood, negative space, small symbolic subject. Exclude crude 3D so the contrast is visible.

`broken_footage`: amateur low-poly 3D render; wrong proportions, stiff pose, blurry textures, mesh holes, clipping, flat default lighting, empty stage-like environment, awkward sincerity. Exclude polished studio animation, cinematic light, photorealism, and clean topology.

`character_reference`: one full-body subject, front/three-quarter view, simple background, stable silhouette and color blocks for reuse in video.

`meme_reaction`: close-up face, one readable reaction, simple background, empty area for a large caption.

Do not rely on image models to spell Chinese titles. Generate clean title space and add exact text during editing unless the user explicitly requests embedded text.

Use original subjects. Never request exact film frames, protected characters, logos, or a living artist's signature style.
