隐私说明

Open NiuLai 采用用户自带模型账户的方式完成视频生成。RunningHub API Key 仅保存在当前浏览器标签页的 sessionStorage，并随同源请求临时转发给 RunningHub；本站不将 API Key、工作流访问密码或上传素材写入持久化存储。

我们保存什么

浏览器本地会保存工作流编号、节点配置和最近 20 条任务的编号、状态与结果链接。启用云端任务存储后，服务端会保存匿名会话编号及上述任务元数据，最长七天，用于防止重复付费提交和恢复任务状态。

你可以控制什么

你可以断开模型账户、清空最近任务，也可以清除浏览器站点数据。请勿在创意、提示词或上传素材中提交身份证件、账户密码等敏感信息。

第三方处理

视频任务由 RunningHub 及用户选择的工作流模型处理，并受相应平台规则约束。提交付费任务前，页面会再次请求确认。
