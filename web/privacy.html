隐私说明

Open NiuLai 采用用户自带模型账户的方式完成视频生成。模型 API Key 仅保存在当前浏览器标签页的 sessionStorage，并随同源请求临时转发给所选服务商；本站不将 API Key、工作流访问密码或上传素材写入持久化存储。

我们保存什么

注册时保存邮箱、随机盐和单向密码哈希，不保存明文密码。浏览器本地会保存未提交的创意、最近一次制作方案、自定义工作流配置，以及最近 20 条任务的编号、模型、状态与结果链接。服务端按账户保存任务元数据最长七天，用于隔离用户、防止重复付费提交和恢复任务状态。用户主动提交的成片评分、问题类型和补充说明最长保存三十天。

你可以控制什么

你可以退出登录、断开模型账户、清空最近任务，也可以清除浏览器站点数据。请勿在创意、提示词、评价或上传素材中提交身份证件、账户密码等敏感信息。

第三方处理

视频任务由用户选择的 MiniMax 官方 API、RunningHub AI 实例或自定义工作流处理，并受相应平台规则约束。提交付费任务前，页面会再次请求确认。
